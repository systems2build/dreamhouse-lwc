# Security

This repository is an **educational fork** of the Salesforce Trailhead Apps Dreamhouse sample. It is not an endorsed production deployment.

For a vulnerability in unchanged upstream Dreamhouse code, use the upstream project's current responsible-disclosure channel, not a public issue containing exploit details. For changes unique to this fork, use GitHub private vulnerability reporting if configured, or a private channel established by the owner. Do not publish credentials, tokens, org identifiers, or security-sensitive details in an issue or pull request.

The upstream's original SECURITY.md directed reporters to security@salesforce.com. That address is not represented as a support contract or security contact for this independently managed fork.

See FORK_STATUS.md for inherited CI/CD and Salesforce credential cautions.
